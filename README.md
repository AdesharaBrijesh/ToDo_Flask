# ToDo App with Flask

![Website Demo GIF](https://github.com/user-attachments/assets/5fefa3fa-c4e4-4ff8-9995-e34ce812518b)


A simple yet powerful **ToDo App** built with **Flask**, **HTML**, **CSS**, and **JavaScript**. This app allows users to create, edit, mark as complete, and delete tasks. It also features a beautiful interactive background and a clean, user-friendly interface.

👉 **Live Demo**: [ToDo App Demo](https://brijesh01.pythonanywhere.com/)

---

## Features ✨

- ✅ **Add Tasks**: Easily add new tasks with a simple input form.
- ✅ **Mark as Complete**: Check off tasks when they are completed.
- ✏️ **Edit Tasks**: Update existing tasks with a single click.
- ❌ **Delete Tasks**: Remove tasks you no longer need.
- 🎨 **Interactive Background**: Enjoy a visually appealing and interactive background animation.
- 📱 **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- ⚡ **Real-Time Updates**: Tasks are managed in real-time without page reloads.

- **Backend**: Flask (Python)

## Installation 🚀

Follow these steps to run the project locally on your machine:

### 1️⃣ Clone the Repository
Clone the repository to your local machine using the following command:
```bash
git clone https://github.com/AdesharaBrijesh/ToDo_Flask.git
```

### 2️⃣ Navigate to the Project Directory
```bash
cd adesharabrijesh-todo_flask
```

### 3️⃣ Set Up a Virtual Environment (Recommended)
Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # For Windows: venv\Scripts\activate
```

### 4️⃣ Install Dependencies
Install the required Python packages:
```bash
pip install flask
```

### 5️⃣ Run the Application
Start the Flask development server:
```bash
python app.py
```
The app will be running at `http://localhost:5000`. Open this URL in your browser to view the application.

## Usage 📋

1. **Add a Task**: Enter a task in the input field and click "Add."
2. **Mark as Complete**: Click the checkbox next to a task to mark it as complete.
3. **Edit a Task**: Click the "Edit" button to update the task text.
4. **Delete a Task**: Click the "Delete" button to remove the task.
